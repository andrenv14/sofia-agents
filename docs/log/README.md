# docs/log/

Meses anteriores do diário, arquivados para o `LOG.md` corrente caber numa
leitura.

Move-se por mês, com o texto integral — não resumido. Resumir o diário apaga
justamente a medição que justificou uma decisão, e sem ela a objeção volta com
outra roupa duas semanas depois e alguém refaz o trabalho para descobrir o que
já se sabia.
